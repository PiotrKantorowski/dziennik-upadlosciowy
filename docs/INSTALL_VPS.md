# Instalacja VPS

Rekomendowany model produkcyjny:

- PHP 8.1+ z Apache/Nginx,
- MySQL 8,
- HTTPS,
- cron dla raportu dziennego,
- wtyczka Chrome/Edge uruchomiona na komputerze użytkownika do obsługi KRZ.

Wtyczka musi wskazywać publiczny adres backendu oraz token KRZ. KRZ działa przez realną przeglądarkę użytkownika, dlatego sam VPS nie zastępuje wtyczki.
