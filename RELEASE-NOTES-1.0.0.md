# DUiR PHP/MySQL 1.0.0

Wersja 1.0.0 obejmuje port aplikacji do PHP + MySQL z integracją wtyczki Chrome/Edge dla KRZ.

## Najważniejsze elementy

- panel podmiotów,
- MySQL schema,
- Docker Compose,
- sprawdzanie KRS/MSiG/KRZ,
- kolejka zadań KRZ dla wtyczki,
- scoring ryzyka,
- obsługa zakończonych niepowodzeniem postępowań restrukturyzacyjnych,
- kontrola sprawozdań finansowych,
- raporty PDF,
- wysyłka e-mail z PDF,
- raport dzienny,
- maskowanie sekretów,
- dokumentacja lokalna/VPS/KRZ/SMTP,
- testy regresyjne.

## Ograniczenia

Nie wykonano live-testu na realnym portalu KRZ w środowisku użytkownika ani wysyłki z realnego konta SMTP. Te testy wymagają aktywnej sesji przeglądarki oraz danych SMTP.
